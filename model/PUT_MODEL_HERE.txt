Place your trained XGBoost model file here, named exactly:

    model.json

app.py loads it at startup via:

    booster = xgb.Booster()
    booster.load_model("model/model.json")

If your model was trained with a pandas DataFrame passed to xgb.DMatrix
(i.e. columns had names), the booster remembers those feature names and
the backend will automatically reindex uploaded files to match them
(missing columns are filled with 0, extra columns are dropped, order is
corrected). If your model has no stored feature names, uploaded files
are used as-is in column order after dropping label/time columns.
